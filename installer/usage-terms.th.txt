WinsAlt: ขอบเขตและข้อจำกัดการใช้งาน

กรุณาอ่านก่อนติดตั้ง การเลือก "ยอมรับ" หมายถึงคุณเข้าใจและยอมรับข้อต่อไปนี้

1. ไม่มีการรับประกัน
WinsAlt เป็นซอฟต์แวร์เสรีภายใต้สัญญาอนุญาต MIT ให้มาตามสภาพ ("as is") โดยไม่มีการรับประกันใดๆ ผู้ใช้รับความเสี่ยงเอง ควรทดสอบบนเครือข่ายของคุณก่อนใช้งานจริง และเก็บ name service เดิมไว้จนกว่าจะมั่นใจ

2. ไม่ใช่ผลิตภัณฑ์ของ Microsoft
WinsAlt เป็นการพัฒนาอิสระของ NetBIOS name service (RFC 1001/1002) ที่เครื่อง client ของ WINS ใช้ ไม่ได้ผลิต สนับสนุน หรือรับรองโดย Microsoft "Windows" และ "WINS" เป็นเครื่องหมายการค้าของ Microsoft Corporation

3. สิ่งที่ทำได้และทำไม่ได้
- ทำได้: ลงทะเบียนและค้นหาชื่อทาง UDP 137, static mapping, replication ระหว่าง WinsAlt, ส่งต่อชื่อที่ไม่รู้จักไปยัง WINS server อื่นและ DNS, และ dashboard บนเว็บ
- ทำไม่ได้: NetBIOS datagram (UDP 138) และ session (TCP 139), replication แบบ Microsoft WINS (TCP 42), และงาน browsing / domain

4. ต้องใช้ UDP 137 แต่เพียงผู้เดียว
บน Windows ต้องปิด NetBIOS over TCP/IP บนทุก adapter ที่ WinsAlt ให้บริการ (ทำได้จาก dashboard) บน Linux ต้องไม่มี nmbd ของ Samba ทำงานอยู่ การทำเช่นนี้เปลี่ยนวิธีที่เครื่องนี้ถูกมองเห็นในเครือข่าย

5. ความปลอดภัยเป็นความรับผิดชอบของผู้ใช้
- Dashboard เป็น HTTP ไม่เข้ารหัส ควรจำกัดผู้ที่เข้าถึงได้ (firewall, เครือข่าย) และเปลี่ยนรหัสผ่านเริ่มต้น admin / admin ทันทีหลังติดตั้ง
- Replication key และ API token เก็บเป็นข้อความธรรมดาในโฟลเดอร์ข้อมูล ควรให้เฉพาะผู้ดูแลระบบอ่านโฟลเดอร์นั้นได้
- ข้อมูล replication ยืนยันตัวตนแต่ไม่เข้ารหัส
- การลงทะเบียนชื่อเปิดให้ทุกเครื่องเป็นค่าเริ่มต้นเหมือน WINS ควรใช้การตั้งค่าความปลอดภัย (วง network ที่อนุญาต, ชื่อที่บล็อก, ขีดจำกัด) ที่เหมาะกับเครือข่ายของคุณ

6. ข้อมูล
ชื่อที่ลงทะเบียน การตั้งค่า และ hash ของรหัสผ่านเก็บในโฟลเดอร์ข้อมูล ควรสำรองไว้ การถอนการติดตั้งจะไม่ลบโฟลเดอร์นี้ เว้นแต่คุณลบเอง

7. ระบบที่รองรับ
ทดสอบแล้วบน Windows 10 และ 11, Debian 13, Ubuntu 24.04 และ 26.04, และ CentOS Stream 10 อาจทำงานบนระบบอื่นได้ แต่ไม่มีการรับประกัน
